A team-built console application in C for donating, requesting and exchanging books, with separate user and admin roles.

The system is backed by MySQL (run through Docker) and lets users list books for donation, request available titles, and exchange books with one another. An admin role handles approval and oversight.

Built as a group project; the source is on GitHub.
